These remotes typically modulate digital data onto a 36–40 kHz carrier using 940 nm infrared light, which provides robust detection in noisy indoor environments and reflects well from ordinary surfaces. The author created software to use such remotes to restore infrared-control functionality to a MacBook.</span><span class='zh'>该项目介绍如何读取大量廉价红外遥控器的编码。这类遥控器通常将数字数据调制到 36 至 40 kHz 的载波上，并使用 940 nm 红外光，从而在嘈杂的室内环境中保持较好的检测能力，也能被普通表面有效反射。作者还编写了软件，利用这些遥控器为 MacBook 恢复红外控制功能。</span></p>
